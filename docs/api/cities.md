# Cities

城市管理全局对象。

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `get` | id | `City` | 根据 ID 获取城市对象 |
| `getAtLocation` | location | `City` | 获取指定位置的城市 |
| `getCityIds` | playerID | `int[]` | 获取指定玩家的城市 ID 列表 |
| `getCities` | playerID | `City[]` | 获取指定玩家的城市列表 |
| `getCapital` | playerID | `City` | 获取指定玩家的首都 |
